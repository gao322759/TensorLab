# MATLAB R2026a UI 设计 token（clean-room 测量 v1）

> 来源：本机 MATLAB R2026a 主窗口截图（1542×830 最大化，浅色主题，中文界面）+ UI Automation 窗口壳测量。
> 采集：2026-11-09，Craft Anything `runtime_ui_read`（clean-room，UIA 窗口壳）+ PowerShell 像素截屏。
> 补采：2026-11-12，三栏布局（Workspace 右置，capture/matlab-3col-layout.png）+ 像素级复测校正（见 §1.1）。
> 合规：仅可见外观范式；MATLAB 图标/文案/专有字体不进入 TensorLab 产物。
>
> **像素基准（2026-11-12 测定）**：本机系统 DPI = 125%（`GetDpiForWindow` = 120），
> 窗口物理 1928×1038；`PrintWindow`（DPI-unaware 进程）输出 1542×830 = **逻辑像素（CSS px）**。
> 本文件所有 px 均为逻辑像素，可直接用于 CSS。

## 0. 渲染架构（决定性发现）

MATLAB R2026a 桌面壳 = **CefBrowserWindow / Chrome_WidgetWin_1 / RootView**（UIA 测得）。
**R2026a 桌面已迁移到 CEF（Chromium/HTML）渲染** —— 我们的 HTML/CSS/JS 原型栈与 MATLAB 自身实现路线一致，
原型资产可预期地接近"像素级可移植"。UIA 树只有 12 个窗口壳节点（CEF 内部 DOM 不进 UIA）——
**布局证据只能来自像素测量**（本文件）+ 未来以 DevTools 协议对照（超出 clean-room，禁用）。

### 1.2 主内容区布局

**出厂默认布局 = 两栏（用户 2026-11-12 确认）**，即 capture/matlab-main-window.png 所示：

## 2. 颜色 token（浅色主题，目测校准 ±3%）

```css
:root {
  /* chrome（2026-11-12 像素复测校正，见 §1.1） */

  --bg-panel:      #ffffff;   /* 面板内容底 */

  --bg-gutter:     #f5f5f5;   /* 编辑器行号列 */
  --bg-banner:     #fdf6d8;   /* 命令行窗口黄色提示横幅 */
  --border-panel:  #d0d0d0;   /* 面板/分组边框（1px） */
  --border-soft:   #ebebeb;   /* 表格行线 */

  --accent-green:  #7cac48;   /* 运行按钮 */
  --accent-stop:   #9a9a9a;   /* 停止（disabled 灰） */
```

## 4. 组件规范（实测）

- **Dock tab 行**：高 28px（2026-11-12 复测，原记 22px）；active 近黑底+白字+顶部蓝色高亮条（深色实测），右端独立 "+" 新建
- **面板头**：高 28px（2026-11-12 复测，原记 22px）；非活动黑底白字（深色实测），**活动面板蓝底 #2E71BF 白字**；左标题（11px），右侧 2-3 个 16px 工具图标（排序/信息/⋮）
- **表格（Workspace）**：列头浅灰底加粗（名称/值/大小/类），行高 18px，行线 #ebebeb，值用等宽字体，类型列灰色
- **编辑器**：gutter 40px 右对齐灰号；代码行高 18px；tab 行含文件名+关闭×+新建+
- **命令行窗口**：`>>` 提示符蓝色等宽；输出等宽黑；顶部可出现黄色横幅（快速入门），横幅高 ~24px 含链接
- **Ribbon 按钮**：小按钮 52×30（图标上、文字下）；大按钮（运行）48px 高带下箭头；组标签 10px 灰色居中
- **全局搜索**：ribbon tab 行右端输入框（深蓝行内白底圆角），占位"搜索 (Ctrl+Shift+Space)"

## 6. 深色主题 token（capture/matlab-dark-theme.png，实测）

```css
:root.dark {
  /* 2026-11-12 像素复测校正（见 §1.1）：实测自 matlab-dark-theme.png 与 matlab-3col-layout.png */
  --bg-titlebar:   #ffffff;   /* 标题栏深色下仍为白底（原记 #1a1a1a 有误） */
  --bg-ribbon-tabs: #144074;  /* tab 行品牌深蓝，与浅色同色（原记 #253047 是内容行误记） */
  --bg-ribbon:     #212121;   /* ribbon 内容行深灰（非深蓝） */
  --bg-panel:      #121212;   /* 面板内容底（实测统一近黑，原记 #2b2b2b 偏浅） */
  --bg-editor:     #121212;   /* 编辑器代码区（与面板同底，无"三层深度"差） */
  --bg-docktab-idle: #333333;
  --bg-banner:     #433302;   /* 命令行横幅深黄褐（原记 #5c4a1e 偏亮） */
  --border-panel:  #454545;
  --border-soft:   #3a3a3a;

  --text-primary:  #e0e0e0;
  --text-muted:    #9a9a9a;
  --text-gutter:   #6a6a6a;

  --accent-blue:   #4da6db;   /* 深色下提亮的蓝（提示符/链接） */
  --accent-green:  #7cac48;   /* 运行按钮绿保持 */

  /* syntax (dark): keyword 亮蓝、comment 淡绿、string 淡紫——与浅色同色相、提亮度 */
}
```

**主题化范式（2026-11-12 校正）**：R2026a 的深色不是全壳反转——**标题栏恒为白底，ribbon tab 行恒为品牌深蓝 #144074**，
深色只体现在 ribbon 内容行（#212121）与内容区（统一 #121212，面板与编辑器无深度分层）；
强调蓝在深色下提亮（#4da6db），运行按钮绿保持不变。

## 7. Figure 窗口 token（capture/matlab-figure-window.png，实测）

- **Figure 是独立顶层窗口**（"Figures" 容器 + "Figure 1 ×" dock tab）——R2026a 把图窗也纳入 dock 体系
- **Figure ribbon 上下文主题化**：深蓝底白字（约 #1f4e79），与桌面浅灰 ribbon 形成强区分——**图窗上下文 = 品牌蓝强调**
- Figure ribbon 组：图窗(active)/格式/工具/布局 四 tab；组为 文件（复制图窗/打印/另存为/显示代码）+ **标注和注解**（标题/副标题/X 标签/Y 标签/图例/颜色栏/网格——48px 大图标）
- 绘图区：白底、线色 --accent-blue、黑色刻度、细灰轴框
- 窗口默认 866×690（本例），可停靠回桌面中央区

## 8. Preferences 对话框（capture/matlab-preferences-dialog.png，实测）

- **CEF 内渲染的模态对话框**：不是独立 OS 窗口（`runtime_ui_read` 只看到 `Chrome_WidgetWin_1` 一个子窗口）——再次印证 R2026a 全桌面为 Web 渲染；因此对话框也用了 HTML 样式体系
- 尺寸约 750×420（本例，随桌面缩放），居中浮层 + 四周半透明遮罩
- 结构：**标题栏**（"设置" + 右侧 × 关闭）→ **左侧树形导航**（可展开：MATLAB ▸ App 设计工具 / Web / 代码分析器 / 变量 / 命令历史记录 / 命令行窗口 / 图像显示 / 图窗复制 / 外观 ▸ 字体 · 颜色 / 工作区 / 工程 / 帮助 / 常规 / 建议 / 当前文件夹 / 比较 / 源代码管理 / 编辑器/调试器）→ **右侧内容区**（未选中时为说明文字"选择树中的元素以对其进行设置。"）
- 顶部含**搜索框**（全对话框设置项过滤），宽约 200px，圆角，左侧放大镜图标
- 深色下延续主题：遮罩加深、面板深灰、树选中项亮蓝条、文字 #e0e0e0
- 交互：单击展开箭头 ▸、选中叶子节点右侧内容切换、"确定/取消/应用"按钮在底部（本次截图为"设置"新版，无底部按钮——即时生效式）

**对标结论**：Preferences 是"树形导航 + 内容面板 + 搜索"三件套范式——与 VS Code 设置页同构，
我们的原型按此实现即可（不需要模态遮罩的阻塞语义，tl-desktop 可用抽屉式侧栏）。
