一条命令开始

cargo run -p tl-cli -- run demos/plot_demo.m

仓库自带 10 个 demo 脚本，覆盖线性代数、FFT、信号、图像、统计、优化与控制。它们同时是验收标准：任何时候都必须零错误运行。

三个入口，同一个内核

入口用途启动方式
CLI脚本执行、REPL、性能基准cargo run -p tl-cli
桌面端编辑器 + 变量面板 + 控制台 + SVG 图窗cargo build -p tl-desktop
MCPAI Agent 通过 stdio 调用cargo run -p tl-mcp-server
设计原则：Engine-first / headless-first。任何功能先在无头 Engine 中可用，桌面 UI 只是它的一个视图；CLI、桌面端与 MCP 不会各自实现一套语义。
