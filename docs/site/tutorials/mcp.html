用 MCP 接入 AI

tl-mcp-server 是一个 stdio 的 MCP（Model Context Protocol）服务器。Claude、Cursor 等 Agent 可以调用它执行 m 代码、读取变量，并拿到可直接理解的图窗 JSON。

启动

cargo run -p tl-mcp-server

服务器从 stdin 逐行读取 JSON-RPC 2.0，向 stdout 写响应；日志走 stderr。协议版本为 2025-06-18。

客户端配置

在 MCP 客户端配置中加入（路径换成你的 release 可执行文件）：

{
  "mcpServers": {
    "tensorlab": {
      "command": "F:\\软件开发\\TensorLab\\target\\release\\tl-mcp-server.exe"
    }
  }
}

五个工具

工具参数返回
run{ "path": "demos/hello_world.m" }控制台文本
eval{ "code": "2 + 3*4" }控制台文本（含 ans = 14）
plot{ "code": "figure; plot(1:5);" }控制台文本 + figures: 后的 FigureScene JSON 数组
vars{}变量表的 JSON 数组
reset{}清空工作区

一次完整会话

请求（每行一个 JSON）：

{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"demo","version":"0.0.1"}}}
{"jsonrpc":"2.0","method":"notifications/initialized"}
{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"eval","arguments":{"code":"A = magic(3); sum(A)"}}}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"plot","arguments":{"code":"t=linspace(0,2*pi,100); figure; plot(t,sin(t));"}}}

要点：

  • initialize 之后客户端发送 notifications/initialized；通知不产生响应。
  • 所有工具结果都是 MCP 的 content 数组：[{ "type": "text", "text": "..." }]。
  • plot 的文本在 figures: 之后附带 FigureScene JSON，Agent 可直接读取曲线数据。
  • 未知工具/方法不会崩溃：未知方法返回 result: null，未知工具返回错误文本。

适合 Agent 的工作流

  1. 用 eval 做小步计算，确认中间结果。
  2. 用 plot 生成图窗，读取 FigureScene 中的 x/y 做判断。
  3. 用 run 执行落盘脚本，复现完整流程。
  4. 用 vars 检查工作区，用 reset 隔离下一次实验。
安全边界：MCP 服务器在本机执行任意 m 代码，等同于本地代码执行。只连接可信 Agent，不要把 stdio 暴露到网络。
