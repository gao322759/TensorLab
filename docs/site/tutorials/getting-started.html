快速上手

目标：在本机构建 TensorLab，运行一个 demo，然后进入 REPL 执行自己的第一段 m 代码。

1. 环境要求

依赖说明
Rust stable2021 edition；建议使用最新 stable 工具链
VS Build Tools（Windows）MSVC 链接器 + 自带 CMake；HDF5 静态构建需要
Node.js（可选）仅桌面端 GUI 冒烟测试需要；缺失时该测试自动跳过
冷构建较慢。内核依赖树包含 parser / HIR / MIR / VM / Cranelift / HDF5，首次全量构建可能需要较长时间；后续增量构建会快很多。

2. 构建与自检

cargo check
cargo test --workspace --exclude tl-desktop -j 2
cargo xtask layers

-j 2 可以避免并发链接冲突；cargo xtask layers 校验 L0-L8 分层规则。

3. 运行第一个脚本

cargo run -p tl-cli -- run demos/hello_world.m

成功时脚本输出写到 stdout，末尾会有一行执行状态（如 [VM 12.3 ms]）写到 stderr。这样重定向 stdout 时不会混入状态行。

换一个更有代表性的：

cargo run -p tl-cli -- run demos/plot_demo.m
cargo run -p tl-cli -- run demos/fft_demo.m
cargo run -p tl-cli -- run demos/optim_demo.m

4. 进入 REPL

cargo run -p tl-cli
>> x = 42
x = 42
>> A = magic(4);
>> vars
  NAME           SIZE            BYTES  CLASS
  x             1x1                  8  double
  A             4x4                128  double
>> help
>> exit

REPL 支持宿主命令 vars / clear / help / figures / version，其余输入交给内核执行。↑ / ↓ 可翻历史（桌面端控制台同样支持）。

5. 写自己的脚本

新建 my_first.m：

A = [1 2; 3 4];
b = [5; 11];
x = A \ b;
fprintf('x = [%.2f %.2f]\n', x(1), x(2));

t = linspace(0, 2*pi, 200);
figure;
plot(t, sin(t));
title('my first plot');
grid on;
cargo run -p tl-cli -- run my_first.m

输出应为：

x = [1.00 2.00]

6. 打开桌面端

cargo build -p tl-desktop

桌面端提供编辑器（Ctrl+Enter 运行）、变量面板、控制台 REPL 和 SVG 图窗。控制台支持右键 Copy / Copy All / Select All / Clear Command Window，以及 Ctrl+L 清空。

常见问题

现象处理
新编译的 exe 被拒绝访问杀软可能短暂锁定可执行文件；等待后重试，或把 target/ 加入白名单
cargo test 链接失败使用 -j 1 或 -j 2 串行化链接
一次性运行显示 [VM ...]预期行为：JIT 分层编译需要同一段代码重复执行；REPL / 桌面端 / bench 才会进入 JIT
