绘图与桌面端

TensorLab 的绘图分两段：内核把图窗导出为 FigureScene JSON，桌面端用自研 SVG 渲染器绘制。CLI 只负责执行，不渲染图窗；MCP 则把 FigureScene 原样交给 Agent。

基本绘图

t = linspace(0, 4*pi, 200);

figure;
subplot(2, 1, 1);
plot(t, sin(t));
title('sin(t)');
grid on;

subplot(2, 1, 2);
plot(t, cos(t) .* exp(-t/6));
title('damped cos');
xlabel('t');
ylabel('amplitude');

把它保存为 plot_two.m 并在桌面端按 Ctrl+Enter，或在 CLI 运行：

cargo run -p tl-cli -- run plot_two.m

CLI 不会弹窗，但会执行绘图语句；桌面端会把每个 figure 渲染成一张 SVG 卡片。

支持的 2D 图型

函数说明

布局与标注：figure、subplot、hold on/off、grid、title、xlabel、ylabel、legend、xlim、ylim。

桌面端界面

区域能力
编辑器m-script 高亮；Ctrl+Enter 运行；Ctrl+O / Ctrl+S 打开与保存
控制台REPL、历史（↑/↓）、右键复制/清空、Ctrl+L 清空
工作区变量名、尺寸、类型、预览值
图窗FigureScene → SVG；支持多轴与刻度标签
About页眉 About 或 F1：版本、内核、兼容目标与许可证

控制台复制与清空

  • 选中文本后 Ctrl+C：复制选中内容
  • 右键菜单：Copy / Copy All / Select All / Clear Command Window
  • Ctrl+L：清空命令窗口（与 MATLAB 的 clc 等价的效果）

FigureScene：给二次渲染留的接口

内核导出的是可直接重放的 JSON：

{
  "createdAt": "...",
  "figure": {
    "layout": { "axesRows": 2, "axesCols": 1, "axesIndices": [0, 1] },
    "metadata": { "axesMetadata": [ { "title": "sin(t)", "gridEnabled": true }, ... ] },
    "plots": [
      { "kind": "line", "x": [...], "y": [...], "color_rgba": [...],
        "line_width": 1.5, "line_style": "Solid", "axes_index": 0, "visible": true }
    ]
  }
}

桌面端只消费渲染所需字段；导出时已剥离重复的 *_source 数组，因此该载荷不用于无损回灌（见 ADR-007）。

已知限制

  • 3D 图（surf / mesh / plot3 / contour）内核可导出，桌面端尚未渲染。
  • 无缩放 / 平移 / hover tooltip / 图例点击；大数据没有 WebGL 加速。
  • 图像工具箱的 imagesc 等按当前渲染器能力展示。
