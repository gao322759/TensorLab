m-script 基础

TensorLab 不发明新语言：解析与求值全部来自 RunMat 内核，目标是 MATLAB 语义。本页只覆盖日常脚本最常用的部分。

矩阵与向量

A = [1 2 3; 4 5 6];      % 2x3
x = 1:5;                  % 1x5 行向量
y = (1:5)';               % 5x1 列向量
z = linspace(0, 1, 11);   % 11 个等距点
I = eye(3);
Z = zeros(2, 4);
N = nan(2, 2);

索引从 1 开始，end 表示当前维度的末尾：

x(1)          % 第一个元素
x(end)        % 最后一个元素
A(2, 3)       % 第 2 行第 3 列
A(:, 2)       % 第 2 列
A(1, :)       % 第 1 行
x(2:4)        % 切片

运算

写法含义
A * B矩阵乘法
A .* B逐元素乘法
A \ b线性方程组求解
A'共轭转置
A .^ 2逐元素平方

R2016b+ 的隐式广播可用：

A = ones(2, 3);
b = [10 20 30];
C = A + b;        % b 自动扩展为 2x3

控制流

total = 0;
for i = 1:10
    if mod(i, 2) == 0
        total = total + i;
    end
end
fprintf('total = %d\n', total);   % 30
k = 0;
while k < 3
    k = k + 1;
end

函数文件

一个文件一个主函数；文件名与函数名一致：

% stats2.m
function [m, s] = stats2(x)
    arguments
        x (1,:) double
    end
    m = mean(x);
    s = std(x);
end

调用：

[m, s] = stats2([1 2 3 4]);
fprintf('mean=%.2f std=%.4f\n', m, s);

局部函数可以放在同一文件末尾；工具箱中的函数就是通过这种形式挂载的。

字符串与输出

name = 'TensorLab';
fprintf('%s %d\n', name, 2026);
disp('hello');
注意：内核 0.6.2 的 + 只接受数值/逻辑，字符串拼接请用 strcat，不要用 +'a' 之类写法。

已知语法差异

少数边界行为与 MATLAB 仍有差异，脚本里可以规避：

  • 切片后缀转置：x(2:end-1)' 目前会被忽略（仍返回列向量）。需要转置时显式赋值后再转置。
  • 标量不是张量：对纯标量做 x(:) 或切片赋值可能报错；工具箱入口通常先向量化。
  • struct 检查：没有 isstruct/iscell，可改用 strcmp(class(x), 'struct')。

完整清单见 gaps.md 的 K 系列与 E 系列。
