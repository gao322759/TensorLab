## 二、本版重点

### 1. 调试器（断点 / 单步 / 继续 / 停止）

RunMat 0.6.2 **没有调试器 API**（只有协作式取消），TensorLab 在宿主层实现 MATLAB
`dbstop`/`dbcont`/`dbstep`/`dbquit` 语义：

- **机制**：存在断点时对脚本做**语句级源码插桩**（`__tl_debug__(N);`，同行插入、行号不变），
  `__tl_debug__` 是经 `inventory` 注册进内核 builtin 表的阻塞式内置函数；
  命中断点时通知宿主并在 Condvar 等待恢复；无断点时走普通执行路径，**零开销**。
- 插桩自动跳过：注释/空行、`...` 续行、括号内换行、块注释、`arguments` 块、
  `function`/`end`/`else`/`case` 等结构行，以及整个 `classdef` 文件。

| 操作 | 入口 |
|---|---|
| 设/清断点 | 编辑器行号区（gutter）单击、`F12`、控制台 `dbstop <line>` / `dbclear <line\|all>` |
| 运行 | Run 按钮、`F5`、`Ctrl+Enter` |
| 单步 | Step 按钮、`F10` / `F11`、`dbstep` |
| 继续 | Continue 按钮、`F5`（暂停时）、`dbcont` |
| 终止 | Stop 按钮、`dbquit` |

暂停时：当前行绿色高亮、行号区绿色箭头、状态栏 `paused · line N`，Run 禁用、Continue/Step 启用。

### 2. 错误处理（对齐 MATLAB）

- 控制台输出 `Error (identifier): message` → `at line N` → 调用栈；
- 错误行在控制台可**点击跳转**，编辑器对应行红色高亮、行号转红；
- 每次运行前自动清除上一轮错误高亮。

### 3. 桌面 UI 对齐 MATLAB R2026a

- 4 个 Ribbon tab：`HOME` / `EDITOR` / `VIEW` / `HELP`（无 Simulink/APPS/PUBLISH）；
- **浅色为默认主题**，深色一键切换并持久化；
- 像素复测度量：标题栏 28 / ribbon tab 行 34（两主题均品牌深蓝 `#144074`）/
  ribbon 内容行 120 / 地址栏 26 / 状态栏 22；
- 活动面板头蓝底 `#2e71bf`；全局搜索位于 tab 行右端；
- 面板双击折叠、跨列拖拽停靠、拖动分隔条、`VIEW → Reset Layout`；
- Preferences（树导航 + 搜索）、About（`F1`）、行号 gutter、`Ln/Col` 状态栏。

### 4. 修复：设置断点后界面"死机"

v0.3.0 预览版中 `run` 是 Tauri **同步命令**，在主线程执行并阻塞 `recv()` 等引擎回包，
导致窗口消息循环停摆（`Responding=False`，Stop 也点不动）。本版：

- `run` 改为 `async` + `tauri::async_runtime::spawn_blocking`；
- 暂停状态改由前端 **80 ms 轮询 `debug_state`** 驱动（事件 `debug-paused` 仅作快路径）；
- `Stop` 无条件调用后端 `stop`，后端在暂停中自动转 `dbquit`。

## 四、已知限制

- **调试器粒度**：语句行级（`else`/`case`/`end` 等结构行不暂停）；暂停期间变量面板不刷新
  （`vars` 与 `run` 共用一条引擎线程）；不支持 `dbstop in <fn>`、条件断点、`dbstack`；
  断点只在当前执行文件生效（进入其它 `.m` 函数不暂停）。见 [gaps.md](../gaps.md) B11。
- **JIT 性能**：release 对照 MATLAB R2023b 仍显著落后（matmul 68x、FFT 30x、向量数学 8.7x、
  标量循环 10125x、函数调用 39870x），0.5x 目标未达成，需 RunMat 上游改动
  （见 [jit-benchmarks.md](../jit-benchmarks.md)）。
- **K13/K14 目录级解析污染**仍存在，工具箱目录隔离继续保留。
- 3D 图（`surf`/`mesh`/`plot3`/`contour`）桌面端未渲染。
- 未做代码签名/公证。

## 五、升级说明

- 版本号统一为 **0.3.0**（workspace / Tauri / xtask / tl-mesh）。
- IPC 契约**向后兼容**：新增 `debug_state` / `debug_set_breakpoints` / `debug_resume`
  与 `debug-paused` 事件；`run` 参数与 `RunReport` 结构不变（`run` 命令现在返回
  `Result<RunReport, String>`，正常路径行为不变）。
- 配置文件与 `toolbox/` 布局不变，可直接覆盖安装。
