## 二、冻结范围（v0.1 契约，改动即破坏下游）

以下内容在 v0.1.x 补丁版本内**不得变更**（如需变更须升 minor 并在 `docs/decisions.md` 记录）：

### 1. IPC / serde 载荷契约
见 `crates/tl-types/src/payload.rs`：

- `StreamEntryPayload` 的 tag 值：`output` / `error` / `clearConsole`（internally-tagged + camelCase）
  - 由测试 `stream_entry_tags_are_camel_case` 钉死
- `RunReport` 字段名：`events` / `resultText` / `error` / `warnings` / `variables` / `figures` / `durationMs` / `usedJit`
- `VariableInfo` 字段：`name` / `className` / `shape` / `bytes` / `preview` / `isGpu`
- `FigurePayload` 字段：`handle` / `sceneJson`
- 由 `crates/tl-commands/tests/engine_contract.rs` 的契约测试钉死

### 2. 分层结构
`crates/tl-*` 的 L0-L8 编号与依赖方向（`tools/xtask` 强制校验）。详见 `docs/architecture.md`。

### 3. 对外名称
- 二进制名：`tensorlab`、`tl-mcp-server`、`tensorlab-desktop`
- 宿主命令名：`help` / `vars` / `clear` / `figures` / `version`
- MCP 工具名：`run` / `eval` / `plot` / `vars` / `reset`
- demo 文件名与"零错误运行"的验收要求

### 4. 控制台输出语义
- 回显（`x = 42` / `ans = 2`）由**内核 console 流**提供，宿主不得重复渲染 `display_events`
  - 由测试 `statement_echo_is_not_duplicated` 钉死
- `;` 抑制回显；`disp` 走 stdout

## 三、已知限制（v0.1 不修，转入 v0.2 跟踪）

完整清单见 `docs/gaps.md`，摘要：

1. **编辑器非 Monaco**：桌面端使用自研 overlay 高亮编辑器（textarea + 高亮层）。功能等价（关键字/内置函数/数字/字符串/注释着色、Tab、Ctrl+Enter），但非 Monaco 组件。
2. **绘图非 Plotly**：使用自研 FigureScene→SVG 渲染器，支持 line/scatter/bar/stem/stairs/area + subplot 网格。大数据量（>10k 点）未走 WebGL。
3. **变量面板预览上限 16 元素**：来自内核 `WORKSPACE_PREVIEW_LIMIT`。非数值类型（char/string/complex/cell/struct）显示 `—`。
4. **无 `help` 内置函数**：RunMat 0.6.2 内核未提供，故由宿主层拦截 `help <topic>` 并提供文档表（10 个主题）。未知主题返回提示。
5. **工具箱未完整**：仅覆盖核心数学/信号/绘图子集，"5 个 MVP 工具箱"是 v0.2 目标。
6. **仅 Windows 验证**：工具链为 MSVC；macOS/Linux 未验证。
7. **无安装包**：release 为裸可执行文件，未生成 MSI/NSIS/DMG。
8. **桌面端 UI 无自动化测试**：HTML/JS 渲染逻辑靠后端契约测试间接保障。
