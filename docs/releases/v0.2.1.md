## 三、本版变更

### Added

- **桌面端 About / 版本显示**：页眉显示 `v0.2.1`；`About` 按钮或 `F1` 打开对话框，
  展示版本、内核、兼容目标与许可证；版本值来自 `app_info` 命令（`CARGO_PKG_VERSION`）。
- **Command Window 复制/清空**：右键菜单（Copy / Copy All / Select All /
  Clear Command Window）、`Ctrl+L` 清空、控制台聚焦时 `Ctrl+A` 全选。
- **文档站 + 教程**：`docs/site/` 离线 HTML（快速上手 / m-script / 绘图与桌面端 / MCP）。
- **JIT 诊断**：`Engine::kernel_stats()`、`tensorlab bench --no-jit`；基准与
  MATLAB R2023b 对照见 [docs/jit-benchmarks.md](../jit-benchmarks.md)。
- **对抗性/防作弊/golden 测试**：`adversarial.rs`（11 条）、demo 关键值快照、
  GUI 结构断言（轴数量 / 折线点数 / 刻度标签）。

### Changed

- 版本号统一为 **0.2.1**：workspace、Tauri、CLI/MCP 均使用 `CARGO_PKG_VERSION`。
- Windows 打包脚本实际跑通，产出 MSI；`-Bundle` 只构建 MSI。
- 工具箱错误消息统一为小写开头、无句号；`optimget` 的 `arguments` 缩进修正。
- **许可表述统一**：TensorLab 自身为 **MIT**；RunMat 统一描述为
  **Apache-2.0 / MIT 双许可**（见 [docs/attribution.md](../attribution.md)）。

### Known Limitations

- **K13/K14 目录级解析污染仍存在**：`toolbox/optim_*`、`toolbox/stats_extra/*`、
  `toolbox/stats_pdf/` 的目录隔离继续保留。`kernel_canaries` 会在内核修复后主动失败。
- **K19 性能上限**：release 对标 MATLAB R2023b 仍显著落后（matmul 68x、FFT 30x、
  向量数学 8.7x、标量循环 10125x、函数调用 39870x）；诊断显示 `native_osr_transfers=0`，
  需 RunMat 上游改动。
- `intlinprog` 在不可行约束上可能长时间不返回；CI 只测合法分支与非法 `intcon`。
- `nlinfit` 对发散指数模型会触发内核 SVD 的 NaN panic；CI 只测收敛模型与长度错误反例。
- `dlqr(...,R=0)` 未校验奇异 R，当前返回有限值。
- 重复极点系统的 `margin` 报 `Pm=0°`（不是 `Inf`），golden 快照固定当前行为。
- `fitcsvm` / `fitcknn` / `crossval` 不在 v0.2 交付面。
