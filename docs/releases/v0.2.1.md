## 三、本版变更

### Added
- 对抗性测试 `crates/tl-commands/tests/adversarial.rs`（11 个测试，覆盖 v0.2 新增的 34 个函数）。
- 防作弊用例：同一函数两组不同输入，输出必须变化（10 个函数）。
- Demo golden 快照：`optim_demo` / `control_demo` 关键打印行逐字/容差断言。
- GUI 结构断言：2 个轴、2 条折线、首线 4 个点、刻度标签与 viewBox（共 8 条断言）。

### Changed
- 版本号统一为 **0.2.1**：workspace、Tauri、CLI/MCP 改为 `env!("CARGO_PKG_VERSION")`。
- Windows 打包脚本实际跑通，产出 MSI；`-Bundle` 只构建 MSI。
- 工具箱错误消息统一为小写开头、无句号；`optimget` 的 `arguments` 缩进修正。
- 工具箱脚本约定写入 [docs/development.md](../development.md) §3.1。

### Known Limitations
- **K13/K14 目录级解析污染仍存在**：`toolbox/optim_*`、`toolbox/stats_extra/*`、
  `toolbox/stats_pdf/` 的目录隔离继续保留。合并探针确认
  `toolbox/optimization`（5 函数）会让 `fminsearch`/`fmincon`/`ga` 失败，
  `toolbox/stats`（16 函数）会让 `nlinfit` 失败。`kernel_canaries` 会在内核修复后主动失败。
- `intlinprog` 在不可行约束上可能长时间不返回；CI 只测合法分支与非法 `intcon`。
- `nlinfit` 对发散指数模型会触发内核 SVD 的 NaN panic；CI 只测收敛模型与长度错误反例。
- `dlqr(...,R=0)` 未校验奇异 R，当前返回有限值。
- 重复极点系统的 `margin` 报 `Pm=0°`（不是 `Inf`），golden 快照固定当前行为。
- `fitcsvm` / `fitcknn` / `crossval` 不在 v0.2 交付面。
