## 二、冻结范围（v0.2 契约增量）

沿用 v0.1 的全部契约（见 [v0.1.md](v0.1.md)），并新增：

1. **工具箱脚本布局**
   - `toolbox/<domain>/<fn>.m` 与 `toolbox/*_extra/<fn>/<fn>.m` 均属于公开交付面；
   - 新增函数必须同步更新对应 `docs/toolboxes/*.md` 与 `docs/parity-checklist.md`。
2. **`DEMOS` 常量**：`crates/tl-commands/src/lib.rs` 中的 10 个 demo 是验收契约，
   文件名与"零错误运行"不得回退。
3. **MEX 命令**：`mex` / `mex status` / `mex load <path>` 的输出语义。
4. **GUI 测试入口**：`apps/tl-desktop/ui/tests/gui_smoke.mjs` 与
   `apps/tl-desktop/src-tauri/tests/gui_smoke.rs` 必须保持可通过。

## 三、已知限制（v0.2 不修，转入 v0.3 跟踪）

完整清单见 [gaps.md](../gaps.md) 与 [kernel-notes.md](../kernel-notes.md) 坑 26–30。

### 功能缺口

- **MEX 透明调用**：`mex load` 只能加载并探测 `mexFunction`；m 代码中 `foo(x)` 仍需内核
  提供宿主函数注册 API（K12），且 `mxArray` ABI 不公开（clean-room 红线）。
- **`quadprog`**：实现与数值已验证，但会污染同目录 `fminsearch` 的编译元数据（K13），暂不交付。
- **IIR 设计族**：`cheby1` / `cheby2` / `ellip` 未实现；`chirp` 未补。
- **图像结构体类函数**：`strel` / `regionprops` / `bwconncomp` 需要 struct（内核无构造器）；
  `adapthisteq` 未实现。
- **模型对象类函数**：`zpk` / `pid` / `pidstd` / `zpkdata`（无对应 class）；
  `fitcsvm` / `fitcknn` / `crossval`（`predict` 为 builtin，无法挂接自定义模型）。
- **`fmincon` 的非线性约束** `nonlcon`：工具箱函数内闭包会丢环境（K15），仅支持线性约束与边界。

### 工程限制

- 安装包（MSI/NSIS/DMG/AppImage/deb）未产出；打包脚本已就绪，需在对应平台执行。
- 图窗仍为自研 SVG 渲染器，无缩放/平移/hover；3D 图未渲染。
- 仅在 Windows + MSVC 验证；macOS/Linux 未实测。
- 仓库无 git，冻结仍以文件快照 + 本文档落地。
